2) Render.com → New → Web Service

   DEBUG               = False
   ALLOWED_HOSTS       = .onrender.com
   CSRF_TRUSTED_ORIGINS = https://*.onrender.com
   PYTHON_VERSION      = 3.12.0

   Ixtiyoriy (Gandalf AI):
   GEMINI_API_KEY      = ...
   GROQ_API_KEY        = ...

   Tavsiya (baza saqlansin):

   Chat barqarorligi uchun (ixtiyoriy):
